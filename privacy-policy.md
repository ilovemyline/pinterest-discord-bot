# Privacy Policy – Pinterest Discord Bot

**Last Updated:** November 11, 2026

## 1. Introduction

Pinterest Discord Bot is a Discord application that allows users to retrieve publicly accessible Pinterest Pin information and display associated images within Discord servers.

We respect user privacy and are committed to protecting any information processed by the application.

## 2. Information We Collect

The application may process the following information:

- Discord user IDs when commands are used.
- Discord server IDs for bot functionality.
- Pinterest Pin URLs submitted by users.
- Publicly accessible Pinterest Pin metadata and image URLs.

We do not request or collect Pinterest account passwords or session cookies.

## 3. How We Use Information

Information is used solely to:

- Process Pinterest links submitted by users.
- Retrieve publicly available Pin information.
- Display Pinterest images in Discord channels.
- Maintain and improve bot functionality.

## 4. Pinterest API

This application uses the official Pinterest API to retrieve publicly accessible Pinterest content.

The application follows Pinterest API policies and does not attempt to bypass Pinterest authentication or access restrictions.

## 5. Data Storage and Security

We do not intentionally store Pinterest passwords, session cookies, or private account credentials.

Any application credentials, including API tokens, are handled securely and are not shared publicly.

## 6. Third-Party Services

The application interacts with Discord and Pinterest services. Their respective privacy policies apply:

- Discord: https://discord.com/privacy
- Pinterest: https://policy.pinterest.com/privacy-policy

## 7. Data Sharing

We do not sell or rent personal information to third parties.

Information is not shared except where necessary to operate the application or comply with applicable laws.
